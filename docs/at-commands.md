# AT コマンドの対応範囲

コマンドごとの意味・応答の形・確認結果の記入欄は、[at-command-table.md](at-command-table.md) にまとめてあります。

## 現状でわかっていること

- 標準コマンド(ITU-T V.250 と 3GPP TS 27.007)は、多くのモデム機器で共通に使えます。このツールが使っているのは `AT+CSQ`(信号強度)と `AT+CREG?`(登録状態)です。
- **IsatPhone 2 固有の AT コマンド仕様は、公開情報では見つかっていません。** どこまで対応しているかは、実機で調べる必要があります。
- 取扱説明書によると、IsatPhone 2 は USB 接続でモデムとして使えます(「IsatPhone 2 Modem」として COM ポートが現れます)。

## 実機で調べる — Probe

```
Probe.bat
```

`probe_commands.txt` のコマンドを順に送り、`OK` / `ERROR` / `NO RESPONSE` の一覧と、各コマンドの生の応答を `probe_YYYYMMDD_HHMMSS.txt` に保存します。

- まず `AT+CLAC`(対応コマンドの一覧)の結果を見てください。対応していれば、その機器が受け付けるコマンドがすべて出ます。
- 調べたいコマンドは `probe_commands.txt` に 1 行足します。
- **読み出し・問い合わせ系だけ**にしてください。`ATD`(発信)、`ATZ` / `AT&F`(リセット)、`AT+CFUN`(機能切替)、`AT+CGPS=1` のような起動・設定系は入れないこと。
- `AT+CGSN` はシリアル番号が出るため、既定でコメントアウトしてあります。結果ファイルを共有するときは注意してください。

## 項目を画面に足す

Probe で `OK` が返ったコマンドを、`Config.ps1` の `$Extras` に 1 行足します。

```powershell
$Extras = @(
    @{ Name = 'Operator'; Cmd = 'AT+COPS?'; Regex = '\+COPS:\s*\d+,\d+,"([^"]*)"' }
)
```

`Regex` の最初のかっこ `( )` に入った部分が、カードの値になります。

## GPS の衛星数・信号強度

- 標準の AT コマンドには、GPS の衛星数や C/N0 を返すものがありません。メーカー独自の拡張になります。
- IsatPhone 2 は GPS 受信機を内蔵していますが、**USB のモデムポートから情報を出せるかどうかは、公開情報では確認できていません**。
- 試すルートは 2 つです。
  1. AT コマンドの独自拡張。`probe_commands.txt` に他社モジュールでの例を入れてあります。`AT+CLAC` の結果から `GPS` / `GNSS` / `POS` / `LOC` を含むものも探してください。
  2. 別の COM ポートに流れる NMEA 出力。デバイスマネージャーで、COM ポートが複数ないか確認します。`$GPGSV` 文から、見えている衛星の数と SNR が分かります。NMEA は連続で流れてくるため、`IsatIo.exe`(1 コマンド 1 応答)とは別の読み取り処理が必要です。
