# AT コマンド表

このツール(`Monitor` / `Probe`)に関係する AT コマンドの一覧です。

- 「意味」「応答の形」は、標準仕様(ITU-T V.250、3GPP TS 27.007)に基づく**一般的な内容**です。
- **IsatPhone 2 が実際に対応しているかは未確認**です。`Probe.bat` を実行し、右端の「IsatPhone 2 での確認」欄に結果を書き込んでください(`OK` / `ERROR` / `応答なし`)。
- 対応範囲の調べ方・項目の足し方は [at-commands.md](at-commands.md) を参照してください。

凡例

| 記号 | 意味 |
|---|---|
| 種別 **読出** | 状態を読むだけ。機器の設定を変えない |
| 種別 **設定** | 機器の設定や状態を変える。Probe には入れない |
| 種別 **動作** | 発信・切断など、実際に動作させる(通話料が発生しうる) |
| 本ツール **Monitor** | `Monitor.ps1` が周期的に送る |
| 本ツール **Probe** | `probe_commands.txt` に入っている |
| 本ツール **Extras** | `Config.ps1` の `$Extras` に書けば画面に出せる |
| 本ツール **発信** | 定時試験発信(`$CallTimes`)で使う |

## 1. 結果コード(応答の終わり)

`IsatIo.exe` は、次のいずれかの行を受信した時点で「応答が終わった」と判断します。

| 結果コード | 意味 |
|---|---|
| `OK` | コマンドを実行した |
| `ERROR` | コマンドが未対応、または構文が不正 |
| `+CME ERROR: <n>` | 機器・ネットワーク側のエラー(`<n>` は原因番号。`AT+CMEE=2` で文字表示にできる) |
| `NO CARRIER` | 接続できなかった、または切断された |
| `BUSY` / `NO ANSWER` / `NO DIALTONE` | 発信時に、話中 / 応答なし / 発信音なし |

| `ATD<番号>;` | 音声発信(末尾の `;` が音声通話の意味) | `OK`(呼出開始)/ `NO CARRIER` / `BUSY` など | 動作 | 発信 | 未確認 |

## 4. 信号・ネットワーク(3GPP TS 27.007)

| コマンド | 意味 | 応答の形 | 種別 | 本ツール | IsatPhone 2 での確認 |
|---|---|---|---|---|---|
| `AT+CSQ` | 信号品質 | `+CSQ: <rssi>,<ber>` | 読出 | **Monitor**・Probe | 未確認 |
| `AT+CSQ=?` | 返しうる値の範囲 | 例: `+CSQ: (0-31,99),(0-7,99)` | 読出 | Probe | 未確認 |
| `AT+CREG?` | 回線交換(音声)網の登録状態 | `+CREG: <n>,<stat>` | 読出 | **Monitor**・Probe | 未確認 |
| `AT+CREG=?` | `AT+CREG` に設定できる値 | 例: `+CREG: (0-2)` | 読出 | Probe | 未確認 |
| `AT+CGREG?` | パケット網の登録状態 | `+CGREG: <n>,<stat>` | 読出 | Probe | 未確認 |
| `AT+COPS?` | 現在の事業者 | `+COPS: <mode>[,<format>,<oper>]` | 読出 | Probe・Extras 例 | 未確認 |
| `AT+CGATT?` | パケット網への接続状態 | `+CGATT: <0 or 1>` | 読出 | Probe | 未確認 |

### `<rssi>`(`AT+CSQ` の 1 つ目の値)

| `<rssi>` | 受信電力 |
|---|---|
| 0 | -113 dBm 以下 |
| 1 | -111 dBm |
| 2 〜 30 | -109 〜 -53 dBm(2 dB 刻み) |
| 31 | -51 dBm 以上 |
| 99 | 不明、または測定できない |

換算式は `dBm = -113 + 2 × <rssi>`(0〜31)です。このツールの画面の `Signal Level` はこの式で計算しています。
`99` はグラフ上では `0` として描きます。

### `<ber>`(`AT+CSQ` の 2 つ目の値)

`0`〜`7` がビット誤り率の段階、`99` が不明です。機器によっては常に `99` を返します(このツールの `Ber` 表示は、返ってきた値をそのまま出します)。

### `<stat>`(`AT+CREG?` の登録状態)

| `<stat>` | 意味 | このツールの既定の表示 |
|---|---|---|
| 0 | 未登録、探索もしていない | 未登録 (Not registered) |
| 1 | 登録済み(ホーム網) | 同期完了 (Registered) |
| 2 | 未登録、探索中 | 衛星探索中 (Searching) |
| 3 | 登録拒否 | 拒絶 (Denied) |
| 4 | 不明 | 不明 (Unknown) |
| 5 | 登録済み(ローミング) | ローミング登録 (Roaming) |

表示名は `Config.ps1` の `$RegText` で変えられます。

## 6. GPS 探索(メーカー独自。IsatPhone 2 の対応は不明)

標準には、GPS の衛星数や信号強度を返すコマンドがありません。次は**他社モジュールで使われている例**を、探索用に Probe に入れたものです。

| コマンド | 他社での意味 | 種別 | 本ツール | IsatPhone 2 での確認 |
|---|---|---|---|---|
| `AT+CGPS?` | GPS の ON/OFF 状態 | 読出 | Probe | 未確認 |
| `AT+CGPSINFO` | 測位情報(緯度経度など) | 読出 | Probe | 未確認 |
| `AT+CGNSINF` | GNSS の状態・測位情報 | 読出 | Probe | 未確認 |
| `AT+QGPS?` | GPS の ON/OFF 状態 | 読出 | Probe | 未確認 |
| `AT+GPSINFO` | 測位情報 | 読出 | Probe | 未確認 |
| `AT+CGPS=1` など | GPS を起動 | **設定** | — (入れない) | — |

衛星数と信号強度(SNR)は、NMEA 出力の `$GPGSV` 文に含まれます。NMEA が別の COM ポートに出る機器もあります(詳細は [at-commands.md](at-commands.md))。

## 7. 使い方の例

`IsatIo.exe` は、コマンドを引数で渡して 1 回だけ送ります。

```
IsatIo.exe COM3 115200 "AT+CSQ" 3
IsatIo.exe COM3 115200 "ATD+819012345678;" 20 "ATH"
```

書式は `IsatIo.exe <ポート> <ボーレート> <コマンド> [待ち秒] [後続コマンド]` です。

引数の説明は、`IsatIo.exe -HELP` でも表示できます。

画面に項目を足すには、`Config.ps1` の `$Extras` に書きます(`Probe` で `OK` が返ったコマンドだけ)。

```powershell
$Extras = @(
    @{ Name = 'Battery'; Cmd = 'AT+CBC'; Regex = '\+CBC:\s*\d+,(\d+)' }
)
```

## 8. コマンドの 3 つの書式

| 書式 | 例 | 意味 |
|---|---|---|
| 実行 / 設定 | `AT+CMEE=2` | 値を設定する、または実行する |
| 読出 | `AT+CREG?` | 現在の設定値を読む |
| 試験 | `AT+CREG=?` | 設定できる値の範囲を読む |

`AT+CSQ` のように `?` や `=` が付かないものは、「実行」(測定して結果を返す)です。
